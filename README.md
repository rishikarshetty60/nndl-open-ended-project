# nndl-open-ended-project
# Pneumonia Detection Using Deep Learning

## About the Project

This project focuses on detecting pneumonia from chest X-ray images using deep learning techniques.

## Objective

The main objective of this project is to develop a deep learning model that can classify chest X-ray images into:

- Normal
- Pneumonia

## Technologies Used

- Python
- Google Colab
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Model

The project uses a Convolutional Neural Network-based deep learning approach for image classification.

MobileNetV2 is also used as part of the deep learning model.

## Dataset

The model is trained and evaluated using chest X-ray images belonging to Normal and Pneumonia classes.

## Project Workflow

1. Dataset preparation
2. Image preprocessing
3. Data visualization
4. Model development
5. Model training
6. Model evaluation
7. Prediction on X-ray images

## How to Run

1. Open the `.ipynb` file in Google Colab.
2. Install the required libraries.
3. Upload or provide access to the required dataset.
4. Run the notebook cells in order.
